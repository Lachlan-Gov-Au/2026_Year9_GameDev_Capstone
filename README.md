GAMEDEV STUDIO — EXAMPLE GAME ANALYSIS
Requirements & Scope
==================================================

EXAMPLE GAME: Reef Rescue
GENRE: 2D top-down collection game
TARGET AUDIENCE: Year 7 science students

FUNCTIONAL REQUIREMENTS
------------------------------
FR1. WASD keys to move
FR2. basic score system
FR3. collectibles and treasure which accounts for your score
FR4. hazards and obstacles which can harm you or make the game harder
FR5. main menu and a victory and loss screen

NON-FUNCTIONAL REQUIREMENTS
------------------------------
NFR1. must run on a school laptop (AMD 7530U with RADEON GRAPHICS)
NFR2. easy-to-understand controls
NFR3. maintenance and troubleshooting should be easy to do
NFR4. game is fairly easy to play first time

CONSTRAINTS
------------------------------
CON1. assets must be royalty free (Or hand made)
CON2. audios, SFX, soundtracks all must be non-copyrighted
CON3. must be made within 8 weeks
CON4. developed only on unity
CON5. child-friendly content only

SCOPE — IN SCOPE
------------------------------
✓ controls
✓ score system
✓ menu

SCOPE — OUT OF SCOPE
------------------------------
✗ extreme graphics
✗ multiplayer
✗ in game purchases

==================================================
